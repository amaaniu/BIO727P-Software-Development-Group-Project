Platform Features

Directed Evolution Workflow

Stage experiments from a known WT protein, parse generation data with QC, and produce interpretable analysis outputs for fast decision-making.

Stage 1

Staging: Protein Selection and Plasmid Validation

UniProt Integration

Enter a UniProt accession ID to fetch and store the WT amino acid sequence and feature annotations for functional domains.

Plasmid FASTA Upload

Upload the corresponding DNA plasmid sequence used as the foundation for the directed evolution experiment.

Circular DNA Validation

Verify the WT coding sequence is present within the uploaded plasmid, including circular wrap-around gene locations.

Stage 2

Experimental Data Parsing and QC

TSV and JSON Support

Ingest experimental outputs in either TSV or JSON formats without forcing one rigid input route.

Dynamic Schema Ingestion

Parse essential fields while preserving additional metadata columns for downstream analysis.

Quality Control Gate

Identify, flag, and reject records with missing essential values such as plasmid variant index.

Stage 3

Analysis and Report Generation

Sequence Processing

Extract gene regions from assembled plasmid DNA, perform in-silico transcription/translation, and classify synonymous/non-synonymous mutations versus WT.

Unified Activity Score

Rank variants with a normalized activity metric (DNA vs protein yield and controls), prioritizing catalytic efficiency over simple overexpression.

Visual Reporting

Generate top-performer tables and activity-per-generation distributions in-app (or downloadable PDF where needed).
